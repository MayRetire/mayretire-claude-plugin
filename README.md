# MayRetire for Claude

This Claude plugin connects three MayRetire planning skills to MayRetire's remote MCP calculation service. Attach an exported MayRetire JSON plan, or ask Claude to create an illustrative plan with you. You can inspect assumptions, compare scenarios, explain results, and run bounded stress or Monte Carlo tests. Focused references cover benefits, accounts, returns, withdrawal strategies, housing, taxes, and planning risk. The service does not connect to your MayRetire account or read plans from your browser storage.

When Claude uses the MCP tools, your supplied plan data passes through Claude and is sent to MayRetire for calculation. Review the [privacy notice](https://ai.mayretire.com/privacy.html) before sharing financial details. You can try the [sample plan](https://ai.mayretire.com/sample-plan.json) first. Results are model estimates, not financial or tax advice.

The plugin includes the skills and remote MCP configuration in one package. If you already added MayRetire as a standalone Claude connector, disable that duplicate connection while testing the plugin. For setup help, see the [Claude instructions](https://ai.mayretire.com/claude.html). Report problems to [support@mayretire.com](mailto:support@mayretire.com).
